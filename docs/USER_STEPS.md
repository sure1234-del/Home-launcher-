# Redmi Pad SE setup

1. Install `Mission-Launcher-APK/app-debug.apk`, open Settings, and set Mission as the default
   launcher.
2. Set a reset password in Settings > Reset and data. Use 6-12 digits; never share the password.
3. Grant notifications from Settings > Permissions. The app will show an in-context rationale.
4. Grant display-over-other-apps for the floating timer and water cards.
5. Grant Usage access for study-app auto-pause and Top App Usage.
6. Enable Notification access only if distraction filtering is wanted.
7. Enable the accessibility service only if Circle/Shorts features are explicitly enabled.
8. Allow Calendar access if Calendar Agenda and free-slot features are used.
9. Open Alarm & reminder settings and allow exact alarms for water/reminders.
10. Open Xiaomi Autostart and allow Mission; set Battery saver to No restrictions.
11. Allow pop-up while running in background if the overlay is unavailable.
12. Add the Zite key in Settings > Zite. Enter provider keys only on the device.
13. Optional: add an Open-Meteo key if a provider key becomes required. Prayagraj is the default
    fixed city and no location permission is requested.
14. Optional Google sign-in/calendar needs the device owner's OAuth client ID; the app remains
    functional without Google.
